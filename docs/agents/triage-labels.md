# Triage Labels

技能使用五个标准分流角色；本文件映射到本项目实际使用的状态字符串。

| 标准角色 | 本项目标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估该议题 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可由自主代理处理 |
| `ready-for-human` | `ready-for-human` | 需要人工实施 |
| `wontfix` | `wontfix` | 不会处理 |

当技能提及某个分流角色时，使用本表右侧对应的标签字符串。若项目标签体系发生变化，修改第二列即可。
