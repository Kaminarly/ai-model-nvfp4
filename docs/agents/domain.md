# Domain Docs

工程技能在探索本项目时应按以下规则使用领域文档。

## 探索前读取

- 根目录的 `CONTEXT.md`；或
- 根目录的 `CONTEXT-MAP.md`，若存在则按其指向读取与当前任务相关的 `CONTEXT.md`；
- `docs/adr/` 中与当前任务有关的架构决定记录。

这些文件不存在时应直接继续，不应将其缺失视为错误。`/domain-modeling` 会在术语或决定真正确定时按需创建它们。

## 布局

本项目采用单一上下文布局：根目录可包含一个 `CONTEXT.md`，架构决定记录位于 `docs/adr/`。

## 术语与决定

议题标题、重构建议、假设和测试名称应使用 `CONTEXT.md` 中定义的术语。若输出与现有架构决定记录冲突，必须明确指出冲突，而不能静默覆盖。
